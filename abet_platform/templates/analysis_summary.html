Summary definitions

Measure: one assessment record, not one student. {% if config.EDITION == 'utrgv_mece' %}Attainment: Expert + Practitioner percentages for an EPAN record.{% else %}Attainment: the percentage in rubric levels marked as attained.{% endif %}

Mean attainment: the average of the selected record percentages, with equal weight for each record. It is not a student-weighted success rate. Measures meeting target: {{ scope_metrics.met_count }} records meet their own target out of {{ scope_metrics.count }}, or {{ scope_metrics.met_rate }}%. That percentage is different from mean attainment.

Missing evidence is not zero. Direct: {{ overview.direct_count }} measures{% if overview.direct_mean is not none %}, mean {{ overview.direct_mean }}%{% endif %}. Indirect: {{ overview.indirect_count }} measures{% if overview.indirect_mean is not none %}, mean {{ overview.indirect_mean }}%{% endif %}. Use the Method filter to separate them.
